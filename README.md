# ChoomLink test builds

Test builds of ChoomLink, a co-op mod for Cyberpunk 2077. Not a public release yet.

Download **ChoomLinkLauncher.exe** from the [latest release](https://github.com/hatfieldnoah-source/choomlink-releases/releases/latest) and run it. It installs ChoomLink and the mods it needs, and updates both when a new build is out.
